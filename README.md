# Auralyn Chord — downloads

**Auralyn Chord** is a live chord visualizer and teaching studio. Part of the Auralyn family (Keystack, Showtime, Chord).

**[Download the latest version](https://github.com/chanoch01/auralyn-chord-releases/releases/latest)**

| Computer | File to pick |
|---|---|
| Windows 10 / 11 | `Auralyn-Chord-Setup-….exe` |
| Mac with Apple Silicon (M1 or later) | `…-mac-apple-silicon.dmg` |
| Mac with an Intel processor | `…-mac-intel.dmg` |
| Chromebook, phone, tablet, anything else | **[Use it in your browser](https://chanoch01.github.io/auralyn-chord-releases/)** |

Notes

- **Windows:** the installer is not code-signed yet, so SmartScreen will warn before it runs. Choose More info → Run anyway.
- **Mac:** the app is not signed with an Apple Developer ID yet. The first time, right-click (or Control-click) the app → Open → Open.
- Each release lists a SHA-256 checksum for every file so you can check the download.
- The desktop app looks here at launch to tell you when a newer version is out. It never downloads or installs anything by itself.
- The browser version can be installed from the browser and works offline. MIDI keyboards need Chrome or Edge (not Safari on iPhone or iPad).
