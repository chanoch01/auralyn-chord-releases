# Auralyn Chord — downloads

Installers for **Auralyn Chord**, the live chord visualizer and teaching studio. Part of the Auralyn family (Keystack, Showtime, Chord).

**[Download the latest version](https://github.com/chanoch01/auralyn-chord-releases/releases/latest)**

- Windows 10 / 11, 64-bit.
- The installer is not code-signed yet, so Windows SmartScreen will warn before it runs. Each release lists a SHA-256 checksum so you can check the download.
- The app looks here at launch to tell you when a newer version is out. It never downloads or installs anything by itself.
