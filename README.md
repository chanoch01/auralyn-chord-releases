# Auralyn Chord — downloads

**Auralyn Chord** is a live chord visualizer and teaching studio. Part of the Auralyn family (Keystack, Showtime, Chord).

- **[Download for Windows](https://github.com/chanoch01/auralyn-chord-releases/releases/latest)** — Windows 10 / 11, 64-bit.
- **[Use it in your browser](https://chanoch01.github.io/auralyn-chord-releases/)** — Mac, Chromebook, phone or tablet. The browser can install it so it opens like an app and works offline.

Notes

- The Windows installer is not code-signed yet, so SmartScreen will warn before it runs. Each release lists a SHA-256 checksum so you can check the download.
- The desktop app looks here at launch to tell you when a newer version is out. It never downloads or installs anything by itself.
- MIDI keyboards work in the browser version where the browser supports Web MIDI (Chrome and Edge; not Safari on iPhone or iPad).
